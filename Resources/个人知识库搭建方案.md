# 📖 个人知识库搭建方案

## 背景

DeepSeek GUI 无内置知识库，利用文件系统 + Obsidian 搭建 PARA 个人知识库。

## 架构

```
┌─ 工作区 (default_workspace) ─────────────────┐
│  knowledge-base/                              │
│  ├─ _index.md         ← 全局索引              │
│  ├─ Projects/         ← 项目（短期任务）      │
│  ├─ Areas/            ← 领域（长期负责）      │
│  ├─ Resources/        ← 资源（参考素材）      │
│  └─ Archives/         ← 归档（已完结）        │
└───────────────────────────────────────────────┘
                    ↕ 双向同步
┌─ Obsidian Vault ──────────────────────────────┐
│  deepseek-kb/  (同上结构)                      │
└───────────────────────────────────────────────┘
```

## 操作流程

| 步骤 | 执行者 | 操作 |
|------|--------|------|
| ① 提炼 | 用户识别 | "记到知识库" |
| ② 写入 | Kun | write/bash 创建/更新 |
| ③ 索引 | Kun | 更新 _index.md |
| ④ 同步 | Kun | 同步到 Obsidian 仓库 |
| ⑤ 查阅 | 用户 | Obsidian 中浏览/编辑 |

## PARA 分类指南

| 分类 | 适合放什么 |
|------|-----------|
| **Projects** | 正在做的任务、有截止日期的目标 |
| **Areas** | 长期关注的领域（工具、健康、财务等） |
| **Resources** | 教程、方法论、参考资料、感兴趣的主题 |
| **Archives** | 已完成的项目、不再活跃的领域、过时资源 |
