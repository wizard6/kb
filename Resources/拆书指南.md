# 📖 拆书指南

> 把一本书拆成能用的东西，而不是读完就忘。

---

## 一、选书（拆之前先判断值不值得拆）

| 问题 | 不值得拆 | 值得拆 |
|------|---------|--------|
| 这本书有核心观点吗？ | 纯信息堆砌 | 有明确论点或体系 |
| 读完我能改变什么？ | 娱乐消遣 | 能影响我的行动或认知 |
| 这本书的结构清晰吗？ | 散乱无章 | 有逻辑框架 |

---

## 二、拆书流程

### 第一遍：速读（30-60分钟）

```
看目录 → 看序言/结论 → 跳读每章标题和小节
  → 标记感兴趣的章节 → 判断核心论点
```

产出：一张纸写下「这本书到底在说什么」

### 第二遍：精读（拆解）

按顺序读标记的章节，同时做三件事：

#### 2.1 摘金句

| 什么样的句子值得记 | 例子 |
|-------------------|------|
| 一句话说清核心观点的 | —— |
| 让你恍然的 | —— |
| 表述极其精妙的 | —— |

#### 2.2 理框架

把作者的逻辑画出来：

```
核心论点
  ├── 论据1 → 关键案例
  ├── 论据2 → 关键数据
  └── 论据3 → 关键推理
```

#### 2.3 写关联

- 这个观点和我已有的认知**冲突**吗？
- 这个观点能**解释**我经历过的什么事？
- 这个观点能**用**在什么地方？

### 第三遍：输出（30分钟）

把拆解结果写成一张纸：

```
书名：《XXX》
核心论点：一句话
三个关键论据：
  1.
  2.
  3.
我的关联：
  冲突：
  解释：
  能用：
行动清单：
  □
  □
  □
```

---

## 三、拆书的原则

| 原则 | 说明 |
|------|------|
| 不追求读完 | 读到没收获就可以停 |
| 不追求记住全部 | 一本书能有3个点用上就值了 |
| 输出驱动输入 | 先想好要输出什么，带着问题读 |
| 关联优先于记忆 | 和自己有关联的内容才记得住 |

---

## 四、不同类型的拆法

| 类型 | 拆法 |
|------|------|
| **方法论**（教你做事） | 重点在步骤和可操作清单 |
| **认知类**（改变看法） | 重点在核心论点和推理过程 |
| **叙事类**（讲故事） | 重点在结构和手法 |
| **工具书**（参考用） | 不需要拆，按需查阅 |
