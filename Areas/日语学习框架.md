# 🇯🇵 日语学习框架

> 记忆 → 考察 → 反馈 闭环。

---

## 一、学习路线

```
五十音        → 2周（平假名+片假名）
  ↓
基础语法      → 2-3个月（助词、动词变形、基本句型）
  ↓
常用词汇      → 持续积累（每天10-15个）
  ↓
听力输入      → 第2个月开始（慢速日语、NHK News Easy）
  ↓
阅读输入      → 第3个月开始（漫画、儿童书、NHK Easy）
  ↓
输出练习      → 第4个月开始（写日记、Shadowing）
```

## 二、每日循环（记忆 → 考察 → 反馈）

```
记忆  ←  学新内容（10分钟）
  ↓
考察  ←  自测/填空/翻译（5分钟）
  ↓
反馈  ←  对答案，标记错误（3分钟）
  ↓
间隔复习 ← Anki / 笔记回顾（5分钟）
```

## 三、能力评级体系

日语能力的主流评级有两个体系：**JLPT（日本語能力試験）** 和 **CEFR（欧洲共同语言参考框架）**。

### JLPT 级别（最常用）

| 级别 | 对应 | 汉字量 | 词汇量 | 能做什么 |
|------|------|--------|--------|---------|
| **N5** | 入门 | ~100字 | ~800词 | 看懂简单打招呼、基本自我介绍 |
| **N4** | 基础 | ~300字 | ~1500词 | 理解日常话题的慢速对话 |
| **N3** | 中级 | ~650字 | ~3700词 | 看懂新闻大意，日常会话基本流畅 |
| **N2** | 中高级 | ~1000字 | ~6000词 | 看懂新闻/评论，能讨论抽象话题 |
| **N1** | 高级 | ~2000字 | ~10000词 | 看懂社论/小说，能应对复杂场景 |

### CEFR 对应

| CEFR | 对应 JLPT | 说明 |
|------|----------|------|
| A1 | N5 | 入门级 |
| A2 | N4 | 基础级 |
| B1 | N3 | 能独立应对日常场景 |
| B2 | N2 | 能理解抽象话题，流畅交流 |
| C1 | N1 | 熟练运用，能理解高难度文本 |
| C2 | — | 母语者水平。日语中无明确对应 |

## 四、时间估算

| 目标 | 学习节奏 | 预估时间 | 说明 |
|------|---------|---------|------|
| **N5** | 每天30分钟 | 2-3个月 | 五十音 + 基础句型 + 简单词汇 |
| **N4** | 每天30分钟 | 4-6个月 | 基本语法体系 + 常用汉字 |
| **N3** | 每天45分钟 | 9-12个月 | 中级语法 + 大量输入 |
| **N2** | 每天1小时 | 1.5-2年 | 新闻/评论阅读 + 听力训练 |
| **N1** | 每天1小时+ | 2.5-3.5年 | 深度阅读 + 输出练习 |

### 从零到最高级（N1）的最短路径

```
N5 → N4（3个月）→ N3（6个月）→ N2（6个月）→ N1（12个月）
                   ↑
            这里开始需要加量
```

**最短约 2-2.5 年**（高强度，每天1-2小时）。
**正常节奏 3-4 年**（每天30分钟-1小时）。
**轻松学 5 年+**（不追求考试，当兴趣慢慢来）。

### 影响速度的关键因素

| 因素 | 影响 |
|------|------|
| 每天投入时间 | 每天30分钟 vs 2小时，差距3倍 |
| 汉字基础 | 中文母语者学日语有天然优势，N1汉字量约2000，中文母语者认识大部分 |
| 听力输入量 | 每天听日语 vs 只靠教材，差距很大 |
| 输出机会 | 会写会说 vs 只读不写，后者到N2后会撞墙 |
| 考试目标 vs 实际能力 | 有人1年过N1但说不出话，有人3年不过N1但能流畅交流 |

## 五、记忆策略

| 记忆对象 | 方法 |
|---------|------|
| 五十音 | 联想记忆 + 手写练习 + 每天默写一遍 |
| 汉字 | 记音读/训读，用 Anki 区分 |
| 动词变形 | 做变形表，来回默写 |
| 助词 | 在句子中记，不单独背 |
| 词汇 | 放在短语/句子里记，不背孤立单词 |

## 六、考察方式

| 考察 | 怎么做 |
|------|--------|
| 填空 | 去掉句子中的助词/动词，填回来 |
| 翻译 | 日→中 / 中→日 交替 |
| 听力听写 | 听一句写一句，核对原文 |
| Shadowing | 跟读音频，录下来对比 |
| 自问自答 | 用日语回答「今天做了什么」「这是什么」 |

## 七、反馈机制

| 反馈 | 怎么做 |
|------|--------|
| 错误本 | 记下常错的助词/变形，每周回顾 |
| 进度记录 | 每天学了什么记一行，看到积累 |
| 里程碑 | 五十音全部记住 → 读完第一篇NHK新闻 → 第一次全对变形表 |

---

> 框架会根据学习进度调整。需要深入某个部分（比如五十音具体计划、Anki牌组模板）随时说。

## 八、N5 快速达标计划（2个月）

> 目标：2个月内具备 JLPT N5 应试能力。每天30-45分钟，周末可加量。

### 第1周：五十音（平假名）

| 天 | 任务 | 用时 |
|----|------|------|
| Day 1 | あ行～か行（あいうえお / かきくけこ） | 30min |
| Day 2 | さ行～た行 + 复习前一天 | 30min |
| Day 3 | な行～は行 + 复习 | 30min |
| Day 4 | ま行～や行 + 复习 | 30min |
| Day 5 | ら行～わ行 + ん + 复习 | 30min |
| Day 6 | 浊音/半浊音/促音/长音规则 | 30min |
| Day 7 | **总复习：默写全部平假名** | 30min |

### 第2周：片假名 + 简单问候

| 天 | 任务 | 用时 |
|----|------|------|
| Day 8 | ア行～カ行 | 30min |
| Day 9 | サ行～タ行 + 复习 | 30min |
| Day 10 | ナ行～ハ行 + 复习 | 30min |
| Day 11 | マ行～ヤ行 + 复习 | 30min |
| Day 12 | ラ行～ワ行 + ン + 复习 | 30min |
| Day 13 | 浊音/半浊音片假名 | 30min |
| Day 14 | **总复习：平假名+片假名混合默写** | 30min |

### 第3周：核心语法（N5必备）

| 天 | 语法 | 例句 |
|----|------|------|
| Day 15 | 〜は〜です / 〜じゃないです | わたしは学生です |
| Day 16 | 〜が〜です（好き/嫌い/上手） | 日本語が好きです |
| Day 17 | こそあど（これ/それ/あれ/どれ） | これは本です |
| Day 18 | 位置（ここ/そこ/あそこ/どこ） | トイレはどこですか |
| Day 19 | 〜を〜ます（他动词） | ご飯を食べます |
| Day 20 | 〜に〜ます（时间/目的地） | 8時に起きます |
| Day 21 | **周复习：前6个语法造句** | 45min |

### 第4周：语法 + 动词变形

| 天 | 语法 | 例句 |
|----|------|------|
| Day 22 | 〜で〜ます（工具/场所） | 電車で行きます |
| Day 23 | 〜へ〜ます（方向）/ 〜と〜ます（共同） | 友達と映画を見ます |
| Day 24 | 形容词（い形容詞 / な形容詞） | 高い / 静かです |
| Day 25 | 形容词否定（くない / じゃない） | 高くないです |
| Day 26 | 过去形（ました / ませんでした） | 昨日勉強しました |
| Day 27 | て形（食べて / 飲んで） | 食べて寝ます |
| Day 28 | **周复习：动词变形 + 造句** | 45min |

### 第5周：语法 + 词汇积累

| 天 | 任务 | 用时 |
|----|------|------|
| Day 29 | 〜たい / 〜たくない | 30min |
| Day 30 | 〜ましょう / 〜ませんか | 30min |
| Day 31 | 〜がある（存在：物） | 30min |
| Day 32 | 〜がいる（存在：人/动物） | 30min |
| Day 33 | 数词（1-10, 百, 千） | 30min |
| Day 34 | 量词（人/本/枚/匹） | 30min |
| Day 35 | **周复习：所有语法过一遍** | 45min |

### 第6-7周：词汇冲刺 + 听力

| 时间 | 任务 | 用时 |
|------|------|------|
| Day 36-42 | 每天15个N5词汇，用Anki记 | 30min |
| Day 43-49 | 每天15个N5词汇 + NHK Easy 慢速听 | 30min |
| Day 50-56 | 每天10个复习 + 日语对话听10分钟 | 30min |

### 第8周：全真模拟

| 天 | 任务 | 用时 |
|----|------|------|
| Day 57-58 | **做一套N5真题，标记错题** | 60min |
| Day 59-61 | 针对错题复习对应语法点 | 30min |
| Day 62-63 | **再做一套N5真题** | 60min |

### N5 通过标准

| 科目 | 满分 | 合格线 |
|------|------|--------|
| 文字・語彙（文字词汇） | 60分 | ~25分 |
| 聴解（听力） | 60分 | ~25分 |
| 読解・文法（阅读语法） | 60分 | ~25分 |
| **总分** | **180分** | **约90分** |
