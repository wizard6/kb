# 🇯🇵 日语学习框架

> 记忆 → 考察 → 反馈 闭环。

---

## 一、学习路线

```
五十音        → 2周（平假名+片假名）
  ↓
基础语法      → 2-3个月（助词、动词变形、基本句型）
  ↓
常用词汇      → 持续积累（每天10-15个）
  ↓
听力输入      → 第2个月开始（慢速日语、NHK News Easy）
  ↓
阅读输入      → 第3个月开始（漫画、儿童书、NHK Easy）
  ↓
输出练习      → 第4个月开始（写日记、Shadowing）
```

## 二、每日循环（记忆 → 考察 → 反馈）

```
记忆  ←  学新内容（10分钟）
  ↓
考察  ←  自测/填空/翻译（5分钟）
  ↓
反馈  ←  对答案，标记错误（3分钟）
  ↓
间隔复习 ← Anki / 笔记回顾（5分钟）
```

## 三、工具推荐

| 工具 | 用途 |
|------|------|
| **Anki** | 间隔重复记忆卡片 |
| **Duolingo** | 入门游戏化练习 |
| **NHK News Easy** | 带假名的简明日语新闻 |
| **Jisho** | 在线日语词典 |
| **MaruMori** | 结构化日语学习 |
| **HelloTalk** | 和母语者交换语言 |

## 四、记忆策略

| 记忆对象 | 方法 |
|---------|------|
| 五十音 | 联想记忆 + 手写练习 + 每天默写一遍 |
| 汉字 | 记音读/训读，用 Anki 区分 |
| 动词变形 | 做变形表，来回默写 |
| 助词 | 在句子中记，不单独背 |
| 词汇 | 放在短语/句子里记，不背孤立单词 |

## 五、考察方式

| 考察 | 怎么做 |
|------|--------|
| 填空 | 去掉句子中的助词/动词，填回来 |
| 翻译 | 日→中 / 中→日 交替 |
| 听力听写 | 听一句写一句，核对原文 |
| Shadowing | 跟读音频，录下来对比 |
| 自问自答 | 用日语回答「今天做了什么」「这是什么」 |

## 六、反馈机制

| 反馈 | 怎么做 |
|------|--------|
| 错误本 | 记下常错的助词/变形，每周回顾 |
| 进度记录 | 每天学了什么记一行，看到积累 |
| 里程碑 | 五十音全部记住 → 读完第一篇NHK新闻 → 第一次全对变形表 |

---

> 框架会根据学习进度调整。需要深入某个部分（比如五十音具体计划、Anki牌组模板）随时说。
