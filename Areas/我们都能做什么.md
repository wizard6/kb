# 🎮 我们都能做什么

> 不知道干啥的时候翻这篇。随时往里加新想法。

---

## 🔍 沉浸类

| 做什么 | 怎么玩 |
|-------|--------|
| 手机考古 | 翻到3年前的相册，删没用的截图和重复照片 |
| 街景 wander | 地图软件街景模式，随机丢到国外小镇云散步10分钟 |
| 听老专辑 | 学生时代循环过的专辑，从头到尾不切歌 |
| 发呆清内存 | 正大光明发呆15分钟，给大脑放空 |

## 🧠 小成就类

| 做什么 | 怎么玩 |
|-------|--------|
| 废物改造 | 外卖袋/快递盒剪成收纳盒，或折川崎玫瑰 |
| 给自己写差评 | 吐槽口吻写50字「退货申请」，理由越离谱越好 |
| 学没用技能 | 用非惯用手写名字写满一张纸，或筷子剥花生皮 |
| 给地图建模 | 凭记忆画你家附近详细地图，标出快递柜/流浪猫窝 |

## 🏃 高能量类

| 做什么 | 怎么玩 |
|-------|--------|
| 红绿灯快走 | 出门遇红灯做10个开合跳，绿灯快走，无目标绕一圈 |

## 💬 社交类

| 做什么 | 怎么玩 |
|-------|--------|
| 随机整活 | 给第8个聊天框发：「我刚学会一个超冷的知识，你想听吗？」 |

## 📝 知识库类

| 做什么 | 怎么玩 |
|-------|--------|
| 记词汇 | 你说「记一个词」，我加进个人词汇表 |
| 写笔记 | 你说「记录一下」，我按原文写入 KB |
| 整理资料 | 你说「整理一下」，我帮你分类归档 |
| 研究课题 | 你说「研究一下XXX」，我出分析文档 |
| 项目分析 | 你说「分析一下XXX」，我出深度分析 |
| 头脑风暴 | 你说「来点想法」，我出方案/思路 |
