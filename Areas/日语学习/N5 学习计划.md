# 📋 N5 学习计划

> 目标：达到 JLPT N5 水平，具备基础日语能力。
> 学习方式：按**单元**推进，每天完成几个单元由你自己决定。

---

## 学习建议

| 项目 | 建议 |
|------|------|
| 每天用时 | 每个单元约15-25分钟。建议每天2-3个单元 |
| 复习节奏 | 每完成一个单元，回顾前一天的内容5分钟 |
| 工具准备 | Anki（记单词）、纸和笔（写五十音）、笔记本（记语法） |

## 一、五十音

### 单元 1.1：平假名 あ行〜か行

| 假名 | 罗马音 |
|------|--------|
| あいうえお | a i u e o |
| かきくけこ | ka ki ku ke ko |

- 练习：每行写5遍，遮住默写
- 产出：能默写这10个假名

### 单元 1.2：平假名 さ行〜た行

| 假名 | 罗马音 |
|------|--------|
| さしすせそ | sa shi su se so |
| たちつてと | ta chi tsu te to |

- 注意：「し」读 shi、「ち」读 chi、「つ」读 tsu
- 练习：写5遍，遮住默写
- 产出：能默写这10个假名

### 单元 1.3：平假名 な行〜は行

| 假名 | 罗马音 |
|------|--------|
| なにぬねの | na ni nu ne no |
| はひふへほ | ha hi fu he ho |

- 注意：「ふ」读 fu，介于 hu 和 fu 之间
- 练习：写5遍，遮住默写
- 产出：能默写这10个假名

### 单元 1.4：平假名 ま行〜や行

| 假名 | 罗马音 |
|------|--------|
| まみむめも | ma mi mu me mo |
| やゆよ | ya yu yo |

- 注意：「やゆよ」只有3个
- 练习：写5遍，遮住默写
- 产出：能默写这8个假名

### 单元 1.5：平假名 ら行〜わ行

| 假名 | 罗马音 |
|------|--------|
| らりるれろ | ra ri ru re ro |
| わをん | wa wo n |

- 注意：「を」读 wo，但现代日语中只作助词用
- 练习：写5遍，遮住默写
- 产出：能默写这8个假名

### 单元 1.6：浊音・半浊音・拗音

| 类型 | 例 |
|------|-----|
| 浊音（＂） | がぎぐげご / ざじずぜぞ / だぢづでど / ばびぶべぼ |
| 半浊音（°） | ぱぴぷぺぽ |
| 拗音（小ゃゅょ） | きゃ / きゅ / きょ / しゃ / しゅ / しょ 等 |

- 练习：写一遍浊音表，重点记「じ/ぢ」「ず/づ」的发音区别
- 产出：能读出浊音和常见拗音

### 单元 1.7：片假名

| 行 | 对应平假名 |
|----|-----------|
| ア行〜カ行 | アイウエオ / カキクケコ |
| サ行〜タ行 | サシスセソ / タチツテト |
| ナ行〜ハ行 | ナニヌネノ / ハヒフヘホ |
| マ行〜ヤ行 | マミムメモ / ヤユヨ |
| ラ行〜ワ行 | ラリルレロ / ワヲン |
| 浊音・半浊音 | ガ行 / ザ行 / ダ行 / バ行 / パ行 |

- 方法：把平假名遮住，看片假名写对应的平假名。来回切换
- 产出：看片假名能读出，看平假名能写出片假名

### 单元 1.8：五十音总复习

- 目标：随机抽一个假名，1秒内读出来
- 自测：默写全部平假名 + 片假名
- 验收标准：**全对且10分钟内完成**

## 二、核心语法

### 单元 2.1：〜は〜です（判断句）

| 句型 | 说明 | 例 |
|------|------|-----|
| AはBです | A是B | わたし**は**学生**です** |
| AはBじゃないです | A不是B | わたし**は**学生**じゃないです** |
| AはBですか | A是B吗？ | あなた**は**学生**ですか** |

- 产出：用这个句型介绍自己（名字、职业、国籍）

### 单元 2.2：〜が〜です（好恶/能力）

| 句型 | 说明 | 例 |
|------|------|-----|
| Nが好きです | 喜欢N | 日本語**が好きです** |
| Nが嫌いです | 讨厌N | 勉強**が嫌いです** |
| Nが上手です | 擅长N | 料理**が上手です** |
| Nが下手です | 不擅长N | 歌**が下手です** |

- 产出：用「〜が好き/嫌い/上手/下手」造3个句子

### 单元 2.3：こそあど（指示词）

| 词 | 意思 | 例 |
|----|------|-----|
| これ / それ / あれ / どれ | 这个/那个/那个（远）/哪个 | **これ**は本です |
| ここ / そこ / あそこ / どこ | 这里/那里/那里（远）/哪里 | トイレ**はどこですか** |
| この / その / あの / どの + N | 这个N/那个N/那个N（远）/哪个N | **この**本は高いです |

- 产出：用こそあど指出身边的3个物品

### 单元 2.4：〜を〜ます（他动词句）

| 句型 | 说明 | 例 |
|------|------|-----|
| NをVます | 做N（V是他动词） | ご飯**を食べます** |
| NをVました | 做了N（过去） | 昨日映画**を見ました** |

- 常见他动词：食べます（吃）/ 飲みます（喝）/ 見ます（看）/ 聞きます（听）/ 読みます（读）/ 書きます（写）
- 产出：用「〜を〜ます」造3个日常句子

### 单元 2.5：〜に〜ます（时间/目的地）

| 句型 | 说明 | 例 |
|------|------|-----|
| 时间にVます | 在时间做V | 8時**に起きます** |
| 地点にVます | 去地点 | 学校**に行きます** |

- 注意：时间词带数字要用「に」，但「今日/昨日/毎日」等不加「に」
- 产出：用「〜に」说「我几点做什么」「我去哪里」

### 单元 2.6：〜で〜ます / 〜へ〜ます / 〜と〜ます

| 句型 | 说明 | 例 |
|------|------|-----|
| NでVます | 用N/在N做V | 電車**で行きます** |
| NへVます | 去N方向 | 東京**へ行きます** |
| NとVます | 和N一起做V | 友達**と映画を見ます** |

- 产出：用「で/へ/と」各造一句，描述日常

### 单元 2.7：い形容詞

| 种类 | 肯定 | 否定 | 过去 | 例 |
|------|------|------|------|----|
| い形容詞 | 〜いです | 〜くないです | 〜かったです | 高い→高くない→高かった |

- 常见い形容詞：大きい/小さい/高い/安い/新しい/古い/暑い/寒い/美味しい/楽しい
- 产出：用3个い形容詞描述身边物品

### 单元 2.8：な形容詞

| 种类 | 肯定 | 否定 | 过去 | 例 |
|------|------|------|------|----|
| な形容詞 | 〜です | 〜じゃないです | 〜でした | 静か→静かじゃない→静かでした |

- 常见な形容詞：好き/嫌い/元気/静か/賑やか/便利/有名/簡単/大丈夫
- 产出：用3个な形容詞描述人或场景

### 单元 2.9：过去形

| 句型 | 肯定 | 否定 |
|------|------|------|
| 动词 | 〜ました | 〜ませんでした |
| い形容詞 | 〜かったです | 〜くなかったです |
| な形容詞 | 〜でした | 〜じゃなかったです |
| 名詞 | 〜でした | 〜じゃなかったです |

- 产出：用过去形说3件昨天做的事

### 单元 2.10：て形

| 变形规则 | 例 |
|----------|-----|
| 〜う→〜って | 買う→買って |
| 〜く→〜いて | 書く→書いて |
| 〜ぐ→〜いで | 泳ぐ→泳いで |
| 〜す→〜して | 話す→話して |
| 〜つ→〜って | 立つ→立って |
| 〜る→〜って | 食べる→食べて |
| 〜ぬ→〜んで | 死ぬ→死んで |
| 〜ぶ→〜んで | 遊ぶ→遊んで |
| 〜む→〜んで | 読む→読んで |
| 不規則 | する→して / 来る→来て |

- 产出：写出5个动词的て形

### 单元 2.11：〜たい / 〜たくない

| 句型 | 说明 | 例 |
|------|------|-----|
| Vますたい | 想做V | 日本**へ行きたいです** |
| Vますたくない | 不想做V | 勉強**したくないです** |

- 产出：用「〜たい」说3件想做的事

### 单元 2.12：〜ましょう / 〜ませんか

| 句型 | 说明 | 例 |
|------|------|-----|
| Vましょう | 一起做V吧（提议） | 映画**を見ましょう** |
| Vませんか | 要不要做V（邀请） | 一緒に**行きませんか** |

- 产出：用「〜ましょう」「〜ませんか」各造一句

### 单元 2.13：存在句（ある / いる）

| 句型 | 说明 | 例 |
|------|------|-----|
| Nがある | 有N（物） | 机の上**に本があります** |
| Nがいる | 有N（人/动物） | 公園**に猫がいます** |

- 注意：物用「ある」、人/动物用「いる」
- 产出：用存在句描述房间里的3样物品

### 单元 2.14：数词与量词

| 数词 | 1-10 |
|------|------|
| ひとつ/ふたつ/みっつ/よっつ/いつつ | 1-5（和语数词） |
| ろっつ/ななつ/やっつ/ここのつ/とお | 6-10 |

| 量词 | 说明 | 例 |
|------|------|-----|
| 〜人 | 人数 | 一人（ひとり）/ 二人（ふたり）/ 三人（さんにん）|
| 〜本 | 细长物 | 一本（いっぽん）/ 二本（にほん）|
| 〜枚 | 薄平物 | 一枚（いちまい）/ 二枚（にまい）|
| 〜匹 | 小动物 | 一匹（いっぴき）/ 二匹（にひき）|
| 〜冊 | 书本 | 一冊（いっさつ）/ 二冊（にさつ）|

- 产出：数出身边3样物品（「本が3冊あります」等）
